# Plex TV Manager

Plex TV Manager is a private, noncommercial, self-hosted media management application developed for personal use.

The application runs on a Windows-based Plex Media Server and provides a browser-accessible dashboard for managing television shows, monitoring media availability, and reviewing server health.

## Features

- Plex television library inventory and season tracking
- Missing episodes and upcoming release monitoring
- TVmaze metadata and episode scheduling
- Streaming-service identification using Plex Collections
- Plex server health and optimization reports
- Library integrity and backup verification
- Mobile-friendly dashboard for local network access

## Planned Features

- TheTVDB metadata integration
- Plex Watchlist synchronization
- External streaming-provider availability
- Watch history and viewing progress
- Health trends, alerts, and maintenance reporting

## Project Status

Personal, noncommercial project. Not publicly distributed.

TheTVDB metadata will be used for personal media organization and informational purposes, with appropriate attribution.

This repository provides project information only. Application source code, configuration files, credentials, and Plex server access are not publicly available.
